# HearthVale documentation

The implementation and regression tests define the behavior of the current v0.1 tree. [Release cleanup handoff](GitHub_Release_Cleanup_Handoff.md) records its latest verification and remaining publication review items.

- [Master design handoff](HearthVale_Master_Design_Handoff.md) preserves the broader design and its current corrections; provisional and future sections are not promises of implemented features.
- [Legacy runtime audit](Legacy_Runtime_Audit_Handoff.md), [magic alignment](Magic_Barrier_Teleport_Alignment_Handoff.md), and [multi-select selling](Multi_Select_Selling_Handoff.md) explain the most recent targeted changes.
- Phase 1–9 briefs/handoffs, playtest reports, the reference study, revision plan, and revision workloop document design history. Later corrections supersede earlier rules where they conflict; in particular, use the runtime audit and magic alignment handoffs when reading older combat/magic proposals.
- The V1 Word design set, architecture contracts, architecture assessment, M0 audit/contracts, milestone reports, and repository reorganization report retain the original implementation rationale and Core/Shell boundary. Their counts, layouts, and statements of unfinished work describe those milestones.

Earlier handoffs name local validation logs, screenshots, snapshots, and debug APKs that were evidence at the time. Those reproducible artifacts were removed during release cleanup; verification summaries and reusable tests remain. Historical artifact paths are provenance, not files supplied with this source repository.
